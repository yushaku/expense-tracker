# Cursor Rules — Expense Tracker

## Documentation Placement

**ALL documentation files** (product specs, feature designs, system designs, architecture docs, plans, notes, README files, etc.) **MUST** be placed in the `docs/` folder at the project root.

- `docs/phases/` — Phase plans and roadmaps
- `docs/features/` — Feature design documents
- `docs/system/` — System design documents
- `docs/superpowers/plans/` — Implementation plans (generated by superpowers)

Do NOT create documentation files in:
- The project root directory
- The `apps/` or `packages/` directories
- Any location other than `docs/` or its subdirectories

## Superpowers Integration

This project uses superpowers skills (located in `.cursor/skills/`). Follow the skill workflows for brainstorming, planning, TDD, debugging, and code review.
